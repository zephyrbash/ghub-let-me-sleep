# GHubLetMeSleep

A small Windows program I wrote in C to terminate the GHub agent process that constantly kept hanging a few times I put my system to sleep.

## Usage

Download the latest `GHubLetMeSleep` binary from the releases tab and put it somewhere on your system. You can pin it if needed to your taskbar or start menu, or, if you're like me, your stream deck.

## Building

This was built with C in CLion and MSVC
